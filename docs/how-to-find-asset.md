# Find Resources

## Search Engineer

Google is all you need. Search with the show name + episode + what you're looking for.

```
doctor who heaven sent subtitle srt
doctor who heaven sent download
```

You might find some useful sites:

- [BBC Writers' Room](https://www.bbc.co.uk/writers/scripts/whoniverse/doctor-who) — official scripts
- [doctorwhoogle.com](https://www.doctorwhoogle.com) — Doctor Who scripts
- [chakoteya.net](http://www.chakoteya.net) — Doctor Who transcripts
- [tvsubtitles.net](https://www.tvsubtitles.net) — subtitles
- [tvsubs.net](https://www.tvsubs.net) — subtitles

Similarly, Search `youtube online download` or `youtube subtitle srt` — there are many sites that let you download YouTube videos or subtitles directly in the browser.

- https://yt1d.net/en11/
- https://downsub.com

## yt-dlp

For bulk downloads, [yt-dlp](https://github.com/yt-dlp/yt-dlp) is the best choice.

```shell
yt-dlp "https://www.youtube.com/watch?v=..."
```
